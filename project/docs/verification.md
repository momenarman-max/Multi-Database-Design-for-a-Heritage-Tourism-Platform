# سجل التحقق المحلي

شُغلت نسخة Windows الأصلية من المجلد المحلي على PostgreSQL 16.6 وMongoDB 7.0.28 وNeo4j Community 5.26.0 وRedis 5.0.14.1. استخدمت الاختبارات برنامج العميل الحقيقي لكل قاعدة. لاختباري الانقطاع تم توجيه العميل المعني إلى منفذ محلي مغلق داخل الاختبار، واستمرت بقية الخدمات في العمل.

| تحقق | النتيجة المشاهدة |
|---|---|
| تهيئة القواعد ثم seed مرة ثانية | 8 مواقع و4 مرشدين، دون ازدواج عدد الزيارات |
| فحص المراجع ثم إدخال جولة اختبار بموقع غير صالح | نجح الفحص قبل الإدخال وكشف المرجع بعده |
| منحنى حالات الحجز | تأكيد ثم إكمال وحدث واحد، ورفض الإكمال المتكرر |
| أهلية المراجعة | رفض الإدخال قبل الإكمال أو بعد الإلغاء، ورفض الدرجة 9 والتقييم الثاني |
| قراءة الصفحة وتعديل الوصف | miss ثم hit ثم miss مع النص الجديد |
| توقف الاتصال بـRedis | bypass مع تعداد الزيارات من SQL |
| فقد اتصال MongoDB في طلب بارد | خطأ ظاهر ومفتاح صفحة غير موجود |
| قراءات النموذج | ترتيب سليم ثم ريم، وتوصية سوق القزازين لنور، وتطابق المتوسطات المحسوبة يدويًا |
| جلسات وقوائم | قراءة معرف الجلسة مع TTL، وتكرار قراءة القائمة يعيد hit |
| SQL وCypher CRUD | إنشاء وقراءة وتعديل وحذف كيان تجريبي؛ فُحص EXPLAIN للاستعلام الزمني |
| ملف العرض | 14 صفحة PDF، ورابط GitHub قابل للنقر في الصفحة الأخيرة |

يُعاد تشغيل المجموعة الكاملة عبر `.\local.ps1 test`. ملف Compose مسار إعداد منفصل؛ لم يُشغّل Docker على جهاز التحقق. الاختبارات موجهة إلى عينة العرض قبل إضافة حجوزات يدوية.
