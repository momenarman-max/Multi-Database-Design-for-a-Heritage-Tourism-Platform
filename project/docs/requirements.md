# من السؤال إلى عملية البيانات
| المستخدم والسؤال | المدخل | العملية والنتيجة | قاعدة الاتساق |
|---|---|---|---|
| المشغل يسجّل زائرًا | اسم وبريد واهتمامات ولغات | register ينشئ حساب عرض ويحدّث عقدة الزائر | بريد فريد في SQL |
| زائر يستكشف موقعًا | معرف الموقع | site يجمع الملف والجولات والإقامات والقريبة والمرشدين والتقييمات | نتيجة كاملة أو خطأ عند غياب مصدر أساسي في القراءة الباردة |
| زائر يختار جولة أو إقامة | معرف الزائر والخدمة والموعد | request-booking يقرأ الكتالوج ويطلب الحجز | يفحص المعرّفات قبل الحفظ ويثبّت موقع الخدمة في السجل |
| المشغل يؤكد الزيارة أو يلغيها | معرف الحجز | confirm / cancel / complete تغيّر الحالة | قفل صف وحدث واحد لكل حجز مكتمل |
| زائر يقيّم تجربة | حجز مكتمل ونص ودرجة | add-review يضيف تقييمًا ويبطل الصفحة | 1–5 وتقييم واحد للحجز |
| زائر يبحث عمّا يناسبه | مدينة ووسم ولغة أو معرف زائر | search يرتب عدد الجولات؛ recommend يعرض زيارات أصحاب الاهتمامات المشتركة | المعرّف المشترك يربط الرسم بالوصف |
| مخطط سياحي يراجع النشاط | الزيارات والحجوزات والتقييمات | analytics يحسب الذروة والمهلة والرضا | وقت UTC موحد؛ الزيارة المكتملة وحدة العد |

صور العينة بيانات وصفية، والأسعار وأوقات الحجز والتقييمات بيانات تعليمية. تشمل التجربة مشغّلًا محليًا موثوقًا ولا تحتاج حسابات سياح حقيقية.
