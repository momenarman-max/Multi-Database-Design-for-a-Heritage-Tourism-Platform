# الاختيارات وكلفة كل منها
| المصدر | سبب الاختيار في هذا المشروع | المقابل |
|---|---|---|
| PostgreSQL | قفل الصف والمفتاح الفريد يربطان الإكمال بحدث واحد، وتخدم SQL حساب المهلة والمتوسط | يحتاج الاستعلام التحليلي الكبير قراءة أحداث كثيرة |
| MongoDB | تختلف بنية الجولة والغرفة والمرشد؛ المصفوفات تحمل اللغات ووسائل الراحة وبيانات الصور | سلامة المراجع العابرة للمجموعات تحتاج فحصًا |
| Neo4j | يجيب انتقالان من الموقع إلى أقرب المواقع والمرشدين، ويعدّ تقاطع التغطية | يتطلب الرسم إسقاطًا إضافيًا للزيارات وإعادة محاولة |
| Redis | جلسات قصيرة وقراءة صفحة مركبة جاهزة بزمن صلاحية معلوم | انتهاء الجلسات أو سقوط الذاكرة ممكن |

**البديل المدروس.** يمكن تنفيذ التغطية في PostgreSQL بجداول قرب وتغطية وربطها بـJOIN ثم GROUP BY. يقلل ذلك عدد الخدمات ويحسّن بساطة النشر. اخترنا الرسم لأن العرض يتطلب استكشاف عدة مسارات بصريًا وتوصيات الزوار عبر علاقات متعددة. تستحق كلفة الرسم المراجعة إذا بقيت الاستعلامات ثابتة وحجم الشبكة صغيرًا.

**التوسع المقترح.** تقسيم أحداث الزيارة حسب الشهر يفيد الأرشفة والتجميع الزمني ويحتاج فهارس محلية. يمكن توجيه قراءات التحليلات إلى نسخة قراءة مع إعلان تأخرها، وإبقاء الحجز على الكاتب. لتوزيع كتالوج MongoDB نختبر مفتاحًا يتضمن المدينة ومعرّفًا عالي التنوع ونراقب المدن الساخنة. احتفظ بعلاقات المواقع المتجاورة قريبة عند تصميم تقسيم الرسم؛ مسارات الزوار بين المدن تزيد عبور الحدود. تُوزع مفاتيح Redis حسب الموقع، وتحتاج سكربتات Lua متعددة المفاتيح إلى hash tags مشتركة قبل الانتقال إلى Redis Cluster.

**CAP وPACELC.** التجربة عقدة واحدة لكل محرك. عند انقسام مجموعة مكررة، اشتراط الأغلبية لكتابة حجز يقلل توافر الكتابة في الجزء المعزول ويحمي ترتيب التغييرات. قراءة كتالوج من نسخة متأخرة قد تبقى متاحة مع بيانات أقدم. حتى عند سلامة الشبكة تزيد الكتابة المتزامنة على نسخ بعيدة زمن الاستجابة، بينما تقبل النسخ غير المتزامنة نافذة فقد أو تأخر. هذه خيارات إعداد وتصميم مستقبلية. لم يُنفّذ عنقود أو اختبار أداء موزع.
