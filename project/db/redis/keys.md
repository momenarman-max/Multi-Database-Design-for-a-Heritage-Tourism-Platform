# مفاتيح Redis
| المفتاح | القيمة | مدة البقاء |
|---|---|---|
| session:&lt;token&gt; | معرف زائر لجلسة عرض محلية | 20 دقيقة |
| site:&lt;UUID&gt;:page | JSON للصفحة العامة | 90 ثانية |
| site:&lt;UUID&gt;:page:version | رقم جيل الصفحة لاكتشاف إبطال متزامن | يوم بعد آخر تعديل |
| listing:&lt;UUID&gt; | جولات الموقع مرتبة بالسعر | 60 ثانية |

ينشئ أمر session رمزًا عشوائيًا، ويقرأه session-check ويحذفه logout. يستطيع مشغل العرض المحلي إصدار جلسة لأي زائر تجريبي. لا تنشر واجهة الأوامر كخدمة حسابات عامة. عند تغيير الكتالوج خارج التطبيق تنتهي نسخ القوائم خلال دقيقة. تعرض cache-info اسم كل مفتاح وحجمه والوقت المتبقي في قراءة Lua ذرية واحدة. تعني القيمة ‎-2 أن المفتاح غير موجود.
